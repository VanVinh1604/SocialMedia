# 📱 Social App - Android

A feature-rich social media Android application built with Kotlin, inspired by Instagram. The app supports posts, reels/short videos, stories, messaging, notifications, and user profile management.

---

## ✨ Features

### 🏠 Home Feed
- View posts from followed users in a scrollable feed
- Like, comment, and share posts
- View stories from friends at the top of the feed
- Post creation prompt with camera support
- Music/audio tag displayed on each post

### 🔍 Search & Explore
- Search for users by name
- View recent search history with quick-remove option
- Explore grid of public posts
- Search reels and media content

### 📸 Upload / New Post
- Upload photos and videos
- Add hashtags to posts
- Select images
- Select videos
- Preview before posting

### 🎬 Reels / Short Videos
- Full-screen vertical video feed (TikTok-style)
- Like, comment, share, and save reels
- Follow creators directly from reel view
- Display caption and hashtags
- Background music/audio display

### 📖 Stories
- Add new stories
- View stories with progress bar
- Story highlights on profile
- Stories storage management
- View story viewers list

### 👤 User Profile
- Personal profile with post grid view
- Edit profile (avatar, bio, personal info)
- View post count, following count, and likes count
- Story highlight collections
- Private account support
- Share profile link
- Two-factor authentication
- Change password
- Password & security settings

### 💬 Messaging / Chat
- One-on-one messaging
- Group chat with member management
- Chat info view
- Chat message bottom sheet options
- Story mentions in chat
- Sticker support
- Real-time online indicator
- Seen/delivered status

### 🔔 Notifications
- Notifications list with time grouping (today, this week, etc.)
- Like, follow, share, and story notifications
- Follow back button directly from notification
- Post thumbnail preview in notifications

### 🧑‍🤝‍🧑 Social / Follow System
- Follow / Unfollow users
- Followers and following list
- Blocked users list and management
- User liked list
- Select users for group or tag

### 💾 Saved / Bookmarks
- Save posts to collection
- View saved posts in profile

### 🔐 Authentication
- Login / Register flow
- Where to log in selection
- Two-factor authentication
- Forgot password / Change password flow

### ⚙️ Settings
- Account center
- Personal information
- Password & security settings
- General settings
- History / Activity log

## 🚀 Getting Started

### Prerequisites
- Android Studio Hedgehog or newer
- Android SDK 24+
- Kotlin 1.9+

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/social-app.git

# Open in Android Studio
# Let Gradle sync complete

# Run on emulator or physical device (API 24+)
```
